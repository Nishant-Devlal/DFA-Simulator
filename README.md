# DFA(Deterministic Finite Automata) Simulator
In this project, I have made a DFA simulator using HTML, CSS and Javascript.  
User will have to enter states of a DFA, alphabets, start state, final state and transitions.  
If the DFA is valid, the output will be a DFA state diagram based on the input.
Then user can enter a string and see if it is valid for this DFA or not and if its accepted by the DFA,
the visualization ans step by step processing will be shown below.
